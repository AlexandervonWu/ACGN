# P0 Variadic Absorption Incident

## Status

Repaired on 2026-08-27. This incident fixes the existing Boolean and
relational lattice theory; it does not add a new rewrite family to bootstrap
theory `R0`.

## Observed Failure

Eight semantically equivalent capability pairs had positive canonical and
typed-canonical distance even though the slotted arm closed them:

| Capability ID | Family | Previous distance |

| `cap000524` | reorder AND | 1 |
| `cap000556` | duplicate AND | 4 |
| `cap000716` | reorder AND | 2 |

| `cap004622` | De Morgan plus reorder | 5 |
| `cap004798` | De Morgan plus reorder | 4 |
| `cap005122` | negation, quantifier, prenex, permutation | 5 |
| `cap005298` | negation, quantifier, prenex, permutation | 4 |

The smallest decisive contextual shape is:

```text
X and A and (A or B) and Y
```

Absorption permits deletion of `(A or B)` only. It does not permit replacing
the complete parent by `A`.

A second witness exposed a separate fixed-point obligation:

```text
X and A and (A or B) and Y and (Y or Z)
```

Both covered OR operands must be removed before the certificate-facing source
snapshot is taken.

## Root Cause

`EGraphNode.parserCertifiedLatticeNormalForm` implemented the binary law
`A and (A or B) = A` by returning `A` whenever it found a matching dual
container. That return is valid only when those are the complete two operands
of the owner. With a variadic owner it discarded every unrelated sibling.

The defect survived because prior tests exercised binary/root absorption but
did not place the redex inside a larger variadic context. After the local fix,
`cap000716` exposed that `NormalForm.normalizeGuardedSourceRules` performed only
one lattice reduction before cloning `certificationMatrixEGraphRoot`, while the
live matrix later reached a fixed point during saturation. The fail-closed
repair kernel correctly rejected the resulting zero-distance/unequal-
observation state.

## Repaired Invariants

1. **Context preservation.** A lattice absorption removes only the matched
   dual-container operand and retains every other owner operand.
2. **Snapshot closure.** The guarded source normalizer reapplies the same
   proved lattice normalization until no strictly reducing absorption or
   factored orientation remains, before cloning the certification matrix.
3. **Kernel agreement.** Repair distance zero and producer-observation equality
   must continue to agree; the kernel check was not weakened.
4. **Authority preservation.** Boolean rewrites still require Boolean rewrite
   authority. Relational rewrites still require parser-certified exact union or
   intersection evidence. No spelling-based or synthetic authority was added.
