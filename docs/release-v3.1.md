# CanDis v3.1: Unary Restrictions and Static Temporal Domains

This research release adds source-level canonicalization for unary restriction and for universal quantification across `always` over static domains. It retains the binding instant for mutable carriers. The Lean development includes a changing-domain counterexample to the unrestricted temporal law.

The frozen implementation was `6648d7bd4148e6374a5446eaf12a3f1d7633db52`. Across 66,080 original files, all 61,598 eligible native comparisons matched, and all 4,482 raw-AST-identical paired files were checked separately in both directions. **4,413** correct distinct-AST student/oracle pairs reached zero distance (+239, no losses); none of the 42,386 incorrect pairs did. All nine `trainStationOld/inv10` SAT counterexamples stayed distinct.

The complete reference-pool search recorded 1,894,168 comparisons for 42,386 incorrect predicates, with 21 raw-AST-identical cross-file comparisons accounted separately (all 21 had different reported support contexts and were not measured). No recorded AST-distinct comparison gave an incorrect nearest-zero match. Among correct references, **11,882 unordered distinct-AST pairs** reached zero (+275, no losses), leaving **2,028** components from 4,496 AST representatives across 181 groups. This is a different population from student/oracle pairs.
