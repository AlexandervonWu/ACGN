# A2-17 ordered projection of admitted ARROW chains

The witness compares the output of public `RepairProjection.project` with independently parsed leaf addresses from the same source bytes and selected predicate. It exercises five admitted chains in three fixtures. All field leaves have the same relation type. The inputs cover two binary operands of inclusion, the opposite associations `(r->s)->r` and `r->(s->r)`, and a single binary operand under `some`.

Before projection, the shared A2-15 checker verifies the actual producer's input digest and declaration, certified source tree, ordered leaf signatures, artifact endpoint multiset and ledger. The A2-17 checker then retrieves the frozen phase through the returned view, resolves each chain's binding by object identity, and checks membership of the exact certificate in the artifact. It checks the view's ordered sequence, result type and number of children. For each child it selects a source leaf by descending the binary tree using left-subtree widths and compares its raw address, field name and exact type with the source, certificate and public output slot.

The receipt contains twelve positive leaf rows and nine rejection rows. Public projection rejects a separately prepared phase even for identical bytes. A dependent binding rejects the other operand's root. The independent checker rejects an equal-type projected field drawn from the wrong slot and a repeated, same-named source occurrence drawn from the wrong address. The two nested roots produce the same public word and distinct binary source addresses.

The six Lean theorems cover arbitrary finite same-head binary trees. Indexed selection by subtree width equals ordered flattening at every index. Following the recovered path gives the original ordinal, so duplicate values at distinct positions retain distinct addresses. Acceptance preserves the owner and every index, and an index disagreement rejects.

The parent remains PARTIAL/DIRECT. This evidence connects the projected values to the authenticated source, adapter result and certificate available during checking. A detached public value carries neither the raw operand association nor a distinct global-field identity for two same-named leaves. The witness covers the static ARROW fragment above.
