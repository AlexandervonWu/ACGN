# G-08 source to wire

For a selected local nullary predicate of the form `some (… -> …)`, this qualification checks one maximal tree of plain binary products whose leaves resolve to immutable local primitive signatures. The verifier accepts an external commitment for this fragment through `--arrow-source-commitment SUBJECT=DIGEST`. Generate both CLI assignments with the caller-side `org.acgn.cert.RawArrowSourcePin SOURCE MODULE/PREDICATE` on the original file. This helper does not open a certificate. The caller supplies those two assignments and the configured theory digest to FULL. The CALL subject uses the qualified predicate and original SHA-256 through the standard CALL subject encoder. Its occurrence list is empty because the entire admitted predicate consists of SOME, binary ARROW and primitive signature leaves. No bundle metadata is necessary to calculate either assignment. The source reader consumes at most 65,536 bytes plus one overflow check.

The subject is SHA-256 over length-framed UTF-8 fields consisting of the versioned subject domain, qualified selected predicate and raw source SHA-256. The commitment hashes its own version domain, the subject, leaf count, each ordered full binary path and resolved signature name, the number of ancestry entries, and each sorted column name followed by the length and members of its ordered direct-parent path. Counts are decimal strings. Each field has a four-byte big-endian byte-length prefix. The caller enumerates the selected AST and reads the actual local `PrimSig.parent` chain to Alloy's built-in `univ`.

The producer witness checks the original retained predicate and ordered leaves against that census, uses the same proof-retaining result for transfer and serialization, and checks the certificate endpoints, source commitment, theory index and unique source insertion owner against the decoded construction. The external pin covers the listed source roles and ancestry. It excludes the opaque serialized producer source-content string. The export witness checks that string against the retained producer occurrence in this exact session. The standalone verifier starts from the published SOME term, follows its actual port invocation and witness to the exact construction target, and checks the complete serialized binary source and its ordered typed roles against the external pin. It compares every encountered declaration ancestry, including paths in intermediate products. The existing parser-subfamily and JOIN-specific holds continue to require independent authority.

Parsed exact leaves may carry a v2 proof even when no subtype conversion is needed. The verifier now reconstructs the complete v2 key for a single exact product of signature columns from the checked DAG, stored type and canonical parser relation spelling. Each new v2 exact case requires successful matching against the external ARROW pin, including when every decoded ancestry has just one member. Existing v1 proof reconstruction remains available. The regression alters a parser spelling and transplants only a foreign DAG child into an otherwise unchanged v2 proof, repairing the outer vocabulary and bundle digests in both cases.

The executable qualification uses TEST_ONLY provenance and the public standalone FULL profile. It covers two binary associations over three distinct signatures with direct-parent chains `A/B/C -> Parent -> univ`. Independent missing or foreign authority, reassociation, leaf permutation, and skipped parent controls exercise the policy. The separate two-root inclusion fixture reaches the producer’s retained-collision export refusal; it produces no wire certificate. For arbitrary field roots, JOINs, mixed operators, general raw normalization, and serialized Java object lineage, closure remains open. Wire ownership binds the source subject, insertion sequence and class identifier. The revision never serializes the in-process lineage counter. External source parsing, the Java-to-Lean correspondence, and SHA-256 collision resistance remain trust assumptions.

`G08ArrowSourceWire.lean` derives uniqueness of arbitrary finite binary signature trees from the complete leaf path census, then derives equality of raw subject, tree and ancestry from accepted payload comparison. The theorem addresses canonical payloads before hashing. Run the registered `org.acgn.cert.ArrowSourceWireRegressionTest OUTPUT.tsv` with `ACGN_SEVENTH_VERIFIER_JAR` set to the freshly built standalone verifier.
