# G-07 bounded nonzero assignment

The fixture selects three nullary predicates from one Alloy module. Each has a conjunction of two `some` or `no` operands over distinct static fields of the same local binary relation type. The source checker resolves both declarations, checks the recorded export source SHA-256 and selected declaration, and reconciles each occurrence with its exact field, type, head, container, size and local address in the certified projection. Both operands of the conjunction belong to its certified SET. The fixture has a single phase, empty binder lists and no alternative representatives.

For an assignment of source operands to target operands, the cost of a paired branch is the sum of its quantifier change and typed field change. Each term is either zero or one. Insertion or deletion of an entire branch costs two. In a two-by-two assignment there are seven partial injections. Sixteen matrix entries in the padded four-by-four production assignment encode these choices with two dummy rows and columns. The Lean theorem `padded_maps_exact` proves that restricting a permutation to its real matches yields precisely the admissible partial injections.

`BoundedAssignmentMinimum.fromSource` takes the raw bytes, both selected names and their actual prepared export projections. Its receipt checker compares both owners and the complete sequence to the program of an attaining assignment. Each program specifies the empty declaration permutation, both wrapper endpoints, and each branch and field address with its charge. Whole branch insertion or deletion names its root. The Java checker independently constructs its scores and programs without invoking a production cost or assignment routine. The Lean model establishes the all-and-only candidate census, exact minimum and acceptance through matching both owners and one complete globally minimizing program. It reasons over already authenticated inputs. The parser, JVM source adapter, comparison of projection nodes to Alloy declarations and the Java-to-Lean correspondence remain trusted.

All three selected raw exports verify under the standalone FULL profile with the independent empty-CALL commitments and registered TEST_ONLY theory pin. Each nonzero comparison has sorted candidate costs `[1, 3, 4, 5, 5, 6, 8]`. The certified occurrence assignments for left-to-right and right-to-left both cross the two ordinals. Left-to-direct keeps both ordinals. The registered native metric and fast metric both attain one. Both native sequences match the independent seven-action program. The controls reject a valid suboptimal sequence, a deleted zero-charge action, a foreign operation address, a redistributed charge, a foreign selected owner, a foreign export selection, and different input bytes. On the left/right exports the standalone PAIR verifier reports `REJECTED/THEORY_MISMATCH` when it compares incompatible common-representative term declarations. The nonzero edit result is checked separately against the owner-bound programs.

This registration provides a bounded subclaim for G-07. Generalized SET sizes, correspondence for arbitrary source and normalized representations, multi-phase programs, other operators, standalone wire edit receipts and unrestricted admissible alignment completeness remain open.
