## Mechanical witnesses

`DecodedEvidenceCoverage.lean` defines a rooted finite term unfolding, a child-indexed and generator-indexed enumeration, and a separate inductive occurrence relation. `walk_exact` and `children_exact` establish membership equivalence in both directions for arbitrary finite trees. The omission, surplus and kernel owner-substitution theorems give failure conditions relative to those derived obligations. A closed tree reuses a binder at two different paths with two generators at each occurrence. In `coordinated_omission_witness` the two remaining ledgers agree after the same omission, but they miss one structurally required path/generator pair. `repeated_reference_preserves_key_set` records the set/multiplicity boundary explicitly.

`org.acgn.cert.DecodedBinderCoverageTest <schema-v8-coverage-directory>` accepts only ordinary positive test fixtures through the standalone FULL entry point. It constructs the empty theory and pins an empty CALL set for each fixture. It reconstructs insertion owners and construction projections from decoded replays, derives binder transpositions from coordinate payloads without reading the encoded generator list, traverses every child and compares projected obligations against each orbit and the record table. Its static fixture expectations are one owned FLAT, CONTAINER and CHAIN row respectively, two independently rooted binders at path [0], and one nested root with paths [0] and [0, 0]. It uses no producer classes. The existing `ProducerSemanticEvidenceMutationTest` checks the public verifier's rejection of paired record/reference omission and cross-owner substitution on encoded bytes.

The Lean occurrences project structural identities onto typed fields and treat the set of descriptor generators as already checked. They do not formalize byte decoding, construction certificate content, event hash injectivity, permutation action, all possible input bytes, or Java-to-Lean program refinement. The Java observation exercises five accepted finite bundles under explicit test assumptions. The kernel owner preimage is modeled as a value; binding it to an actual event is checked by the Java observation. The aggregate closure driver owns the two-build decision.
