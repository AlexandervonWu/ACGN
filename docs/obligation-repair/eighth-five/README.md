# Eighth batch of public certification obligations

The starting revision is `7aa4d5029f7b4078b40f581d949d5f8ffe1ce4d2`. The ranking prioritizes original statements whose admission conditions can be identified in the shipped implementation. The third and fourth rows both require correspondence between a structured preimage and its encoding. The fifth row requires a general result for finite families.

| Rank | Original row | Evidence required for admission |
| ---: | --- | --- |
| 1 | P6-11 | Verify that each source-built and in-scope distributed certificate-verification entry point admits the named feature contract only after an exact schema-v10 check. Test both operands of PAIR independently, and account for what the inspection entry points actually return. |
| 2 | P1-15 | Match the complete fixed import ledger to the pinned library declarations and trace module, callable kind, member and arity through producer admission. Include the two arities of `integer/min` and `integer/max`. Distinguish fixed-ledger membership from the origin of loaded module bytes. |
| 3 | P4-11 | Bind each observed shape ID to its complete owner and canonical term ID throughout the bundle. Recompute deterministic wire framing on both sides and demonstrate what happens when two different observed preimages have the same digest. |
| 4 | P6-09 | Recover the enclosing root, path, descriptor occurrence and automorphism on both producer and replay routes. Follow all supported term and port constructors to the real key encoding and orbit check. |
| 5 | A2-23 | Prove ordered Cartesian enumeration for arbitrary admitted finite product families. Relate it to Java iteration, subsequent normalization, nested products and repeated column occurrences. |

The original text for each row is in the [claim ledger](../../section3-repair-audit/claim-ledger.md). The [scope inventory](../../section3-repair-audit/assurance-scope.tsv) and [traceability matrix](../../section3-repair-audit/requirements-traceability.tsv) record the claim digests.
