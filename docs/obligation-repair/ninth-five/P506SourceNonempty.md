## Declaration authority

The pinned parser adapter calls its inherited node map from the original `RelDecl(Node, Decl)` and `VarExpr(Node, ExprVar)` constructors. The private model-local binding index observes these callbacks during model construction and seals before returning the `ModelUnit`. For each parameter or quantified declaration, it compares the ordered wrapper variables to the exact members of the original Alloy `Decl.names` by object identity. Each slot carries its original declaration, tuple position, resolved `ExprVar` and effective multiplicity. A read must retain the matching original variable and spelling. A declaration receives authority only while the current adapter observations still match the sealed source observations. At seal time, the model records each declaration and the reachable nodes of its variables and domain in a shared identity map. For each node it records the parent and Type object identities, the operation or name, applicable flags, the ordered generic child identities and the ordered named operand identities. The raw adapter and MASG visitor use different child accessors. The pinned parser permits mutation through both access paths, and its setters can change one without updating the other. At collection time the check traverses both sets of saved edges using object identity. A changed view, previously unknown node or missing view withholds the slot. The work per check scales with the size of that declaration's reachable projection, with shared references visited once. This check applies to ordinary sequential parser/adapter conversion. It supplies no synchronization for external writes racing the conversion.

Effective multiplicity uses the original resolved domain. An undecorated unary declaration receives Alloy's implicit ONE. The bare binary product remains SET. The distinction matters for predicate parameters, whose `Expr.mult()` alone can return SETOF for a bare unary domain. The executable inventory includes the installed translator's `addOne` and `Expr.mult` methods. Explicit ONEOF, SOMEOF, LONEOF, SETOF and EXACTLYOF keep their respective meanings. Only ONEOF and SOMEOF can authorize a fold.

* The MASG visitor checks the original read against the lexical symbol and issues an observation for that exact node, graph and visit. The IR traversal can deliver the observation only to its newly allocated recipient. Canonical declaration frames join the observed ordered declaration slot to the observed variable. Admission requires an original frame for the same quantified object, matching current cardinality, an exact read-slot match, and either this phase or an ancestor reached through registered temporal references. Generic parameters and inherited alias maps have no independent authority. In-place adoption transfers the replacement's origin. Collapse or retirement clears it. Source-preserving clones transfer compatible origins. The canonical carrier-witness consumers share the same frame check.
* The raw adapter emits a declaration from a private constructor that retains the observed tuple slots. Variable reads carry their parser-issued slot. The shared rewriter requires a visible binder with the same slot as the read, an owned definition, and an appropriate current domain form. An unowned inner binder masks an outer binder with the same spelling. The ordinary term factories supply no source authority. Trusted normalization, renaming, storage conversion and slot-type erasure transport the original metadata for their respective operations.

## Normal application checks

The ablation regression constructs raw terms and also compares parameters read by the Alloy parser. The raw bare and SOME labels withhold authority for both membership directions. The parsed bare unary, ONE and SOME declarations supply it. SET, LONE and shadowed declarations retain the cardinality of the selected source slot. The test exercises all six engine configurations.

In the ordinary `joinBoundSlots` fixture, `a: set U` is unary and `r,s: U->U` are binary. All three declarations have SET multiplicity. The producer certifies the two binary coordinates in one exchange group and the unary coordinate in another. Reconstructing that partition from the coarse type name `U` alone incorrectly joined the groups and caused the distance calculation to throw. The metric now compares the structured type and domain within the same owner and when checking repeated sightings of a coordinate. It still requires exact equality of the reconstructed and reported groups.
