# Ninth batch of public certification obligations

These five original Section 3 requirements are ranked by dependency. Normalization and intersection supply premises for the JOIN matrix. The encoder and decoder must then retain every decision made by that matrix. The fifth requirement follows a separate path from a parsed Alloy declaration to an authorized simplification.

| 2 | A2-22 | Coordinate-by-coordinate intersection |

| 4 | A2-25 | Versioned DAG and combination-matrix encoding |
| 5 | P5-06 | Declaration authority for binding nonemptiness |

## A2-21

A dependent relation family is a finite normalized union of correlated ordered products; normalization removes duplicate products, absorbs only authenticated componentwise subtypes, and retains incomparable siblings.

Duplicate alternatives must retain the declaration evidence needed for subsumption. Compare permutations of the same raw family, and prove the exact criterion for retaining a product.

Original claim SHA-256 `4bf2b29d09a49228b6013a04ae6d04576b2e092719bf27e3b9a9d320d0fdd6d3`.

## A2-22

Dependent intersection uses componentwise exact or subtype meets and omits only authenticated disjoint branch pairs; two divergent concrete branches whose first common ancestor is only `univ` have no meet, while an explicit `univ` endpoint participates by exact identity or authenticated subtype.

Relate each accepted overlap or disjoint decision to the resolved declaration hierarchy. Follow the result through every column and every pair of products, including explicit univ endpoints.

Original claim SHA-256 `c4c3d3558acdd3162344346a38cf3f320b80486d1626ebdc8d7558cebf129a98`.

## A2-24

Dependent JOIN decides every left/right alternative pair, retains exact or subtype overlaps, omits authenticated disjoint pairs, records a complete row-major decision matrix, and preserves an all-disjoint positive-arity result as a typed empty family.

Check each source pair in row-major order and the exact columns contributed by an overlap. Record the resulting arity for disjoint and empty families, including the case where normalization removes a duplicate result.

## A2-25

Wire schema v10 commits the complete correlated type DAG and dependent combination matrix; schema v9 and earlier inputs are rejected rather than reinterpreted.

Bind ordered products, type references, ancestry, boundaries, decisions and result rows to their wire fields. Check the schema gate, the registered producer and the independent decoder.

## P5-06

Only authenticated ONE or SOME binding tuples authorize static nonemptiness; EXACTLY-of, univ without a separate inhabitant witness, and synthetic opcode labels do not.

Trace a positive membership simplification back to its declaring parser object and active scope in both canonical normalization and ablation. Cover genuine implicit unary bindings, explicit ONE/SOME and nonpositive cases.
